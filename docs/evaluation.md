# SEC-RAG 评价执行方案：收敛版（2026-09-24）

## 状态与研究目标

本文件是当前评价定义入口，替代旧版方案。指标已选定，v4适配实现已通过离线测试，但模型实际运行和自动评价器可靠性尚未验证；现有 four-methods-v3 分数不是本方案的正式结果。当前已修改评价程序；未修改主方法、未运行模型。目录整理后本文件位于 docs/evaluation.md。

研究问题：在相同问题、生成模型、指南库与共同初始检索结果下，生成前证据约束能否减少答案中无法由给定指南证据支持的医学陈述？不能预设 SEC-RAG 一定优于基线。

评价的是相对于给定证据的忠实性，不是临床正确率。证据中找不到某个陈述，不足以证明该陈述在医学上错误。

## 1. 主指标：Faithfulness（忠实性）

出处：[RAGAS，EACL 2024 演示论文](https://aclanthology.org/2024.eacl-demo.16/)；[官方 v0.2.5 定义](https://docs.ragas.io/en/v0.2.5/concepts/metrics/available_metrics/faithfulness/)。

输入：原始问题、最终答案、该题各 RAG 方法共同获得的原始 BM25 Top5 片段。不能只用 SEC-RAG 筛选后保留的证据来评 SEC-RAG。

过程：从答案提取可核验陈述，再判断给定证据是否支持各陈述。语言模型承担提取与语义判断，程序负责计数计算；语言模型不是计算器。

公式（纯文本）：

    单题忠实性 = 被给定证据支持的陈述数 / 被评价的陈述总数

输出：陈述列表、逐条支持判断与依据、支持数、总数、单题分数、原始评价请求与响应。分数越高，表示被评价的内容越忠于给定证据。

医学场景适配：排除标题、礼貌语、单纯证据不足说明，评价实质医学陈述；此筛选及中文提示词属于适配，必须披露，不能宣称完全复现官方实现。复合句需按确定的陈述提取规则处理，不能为个别方法调整边界。

没有实质医学陈述的答案记 N/A，不能把完全拒答记满分。失败或无法完成判断另记状态，不作为零分或拒答。主表报告有效题的单题分数均值，同时报告有效题数与陈述数。1减忠实性只是同一指标的补数，不另外创造一个指标名称。

裸模型也可在生成后接受同一证据池审查，但须说明它生成时没有接收证据。该比较不代表其医学知识正确率。

## 2. 辅助指标：Citation Recall（引用召回）

出处：[ALCE，EMNLP 2023，§3.3](https://aclanthology.org/2023.emnlp-main.398/)。

输入：最终答案中的被评价句子、句子的引用标识、引用所对应的真实指南片段。引用解析必须保存原文与出处，SEC-RAG 的证据单元还需保留原始片段中的适用条件。

过程：检查该句是否带有效引用，以及这些引用拼接后能否支持整个句子。出现引用编号不等于获得支持。

    单句得分 = 1：存在有效引用，且联合引用内容支持整句
    单句得分 = 0：无引用、引用失效或联合内容不支持整句
    单题引用召回 = 单句得分之和 / 被评价句子数

输出：逐句原文、引用映射、支持判断及依据、单题分数。医学句筛选与上下文解析属于本实验适配，须记录；不可把先前的“被支持事实比例”直接称为原版 ALCE 引用指标。

裸模型不要求提供引用，对应列记 N/A。无实质医学句同样记 N/A，另报数量。原论文的评价模型与我们的本地模型不同，因此不能直接继承其可靠性结论。

## 3. 必须随分数报告的数量

同一张四方法对照表展示忠实性、引用召回、各项有效题数、完全证据拒答数、评价失败数。完整结果另保留每题四方法答案对照。

完全证据拒答指没有实质医学回答、明确表示证据不足；空答案、程序失败和其他无内容输出不能自动算拒答。

    完全证据拒答比例 = 完全证据拒答题数 / 成功完成答案类型判断的题数

这是一项描述性计数，不是新的质量指标。其作用是解释分数的分母：一个方法只回答8题，另一个回答29题，不能仅凭前者忠实性更高就声称整体更优。可补充共同有实质回答题目的配对结果，但必须同时保留全量数量，避免隐藏拒答。

## 5. 自动评价的可靠性边界

公开公式不保证本地4B模型能正确提取和判断医学陈述。已有范围误判说明这一点。1题、9题诊断只能检查流程和已知错误；重复一致也不等于正确。

优先对照公开实现核对提示词、陈述单位和聚合方式，再决定实现适配。没有专家标注时，可以报告透明的自动评价结果及局限；不同评价模型的敏感性比较只能提供补充证据，不能替代医学金标准。不能保证审稿人会接受，也不能把自动评分当作临床结论。

当前评价模型选择尚未最终锁定；本文件不授权隐藏下载、切换模型或付费调用。

## 7. RAGAS 与本地评价器：依据及本次实现修订

原论文第3节使用通用 gpt-3.5-turbo-16k 执行评价提示词，并未报告为此训练专用医学评价模型。第4—5节使用50个 Wikipedia 页面构成 WikiEval，由两名英语流利的标注者提供比较判断；表4忠实性偏好与人工一致度为0.95。该数字是其数据上的成对偏好一致度，不是医学陈述判断准确率，更不是我们4B评价器的准确率。

“运行指标不需要参考答案”和“验证指标时使用人工判断”是不同的事情。不能由RAGAS有公开实验推断任意替换模型、语言和领域后仍有相同可靠性；也不能只因模型为4B就断言不可用。我们的疑虑来自已观察到的条件/人群范围误判和输出结构故障，仍须区分代码故障与模型语义误判。

本次实现版本为 four-methods-v4，仍是参考公开定义的医学适配，不是直接调用 ragas 软件包。变化如下：

- 删除主入口中的信息需求拆分、完整性、关注度和单条引用支持调用。
- 忠实性先提取医学陈述，再用共同原始检索片段判断支持；保存陈述与来源句的映射。
- 引用召回按完整句子/行评价，不再按“但未明确”等短语切分引用评价单元。医学内容分类仍为自动模型判断，这是实现限制。
- SEC引用保存实际引用文本和原始片段；后者仅恢复适用条件，不作为额外获准引用事实。
- 失效引用计不支持，完全拒答记N/A，失败另记；保存各分子、分母、输入和模型轨迹。
- 新目录默认 storage/experiments/evaluation/pilot/four-methods-v4/<时间>/。main_quality_evidence_table.csv 为汇总，same_question_comparison.csv 为同题不同方法的答案和分数；questions/<qid>/<method>.json 保存逐步评价记录。
- 旧v3结果保留，新版不能续跑旧结果。52项离线测试通过，其中5项新测试验证公式分母、失效引用、拒答、裸模型N/A及提取完整性；这不证明模型语义准确。

当前没有新增依赖、没有切换模型、没有调用付费API。下一次模型运行属于新口径的开发评价，不是正式测试结论。


运行准备检查：53项离线测试通过；旧30题120份答案输入检查通过；新随机30题清单哈希检查通过。主方法12份快照文件未变。本轮未调用模型。新增评价前全量输入检查、输入哈希续跑校验，以及代码/提示词/定义原文快照保存；没有新增指标。

本轮只读取已生成的3题12份回答，不重新生成答案。输入目录为storage/experiments/testing/framework/cmedqa2_smoke3_20261006。任务配置在configs/tasks.json的evaluate.smoke3中；评价算法、提示词和公式不变。

```bat

```

第一条只检查输入，已确认3题12份答案可读取。第二条由使用者运行本地Ollama qwen3:4b-instruct，workers=2，不调用DeepSeek。
