# 评价定义与运行

评价给定证据对回答的支持程度，不是临床正确率。两个指标参考公开定义作医学场景适配，不是直接调用官方RAGAS软件包。没有对本地评价器正确性作保证。

## 1. 主指标：Faithfulness（忠实性）

出处：[RAGAS，EACL 2024 演示论文](https://aclanthology.org/2024.eacl-demo.16/)；[官方 v0.2.5 定义](https://docs.ragas.io/en/v0.2.5/concepts/metrics/available_metrics/faithfulness/)。

输入：原始问题、最终答案、该题各 RAG 方法共同获得的原始 BM25 Top5 片段。不能只用 SEC-RAG 筛选后保留的证据来评 SEC-RAG。

过程：从答案提取可核验陈述，再判断给定证据是否支持各陈述。语言模型承担提取与语义判断，程序负责计数计算；语言模型不是计算器。

公式（纯文本）：

    单题忠实性 = 被给定证据支持的陈述数 / 被评价的陈述总数

输出：陈述列表、逐条支持判断与依据、支持数、总数、单题分数、原始评价请求与响应。分数越高，表示被评价的内容越忠于给定证据。

医学场景适配：排除标题、礼貌语、单纯证据不足说明，评价实质医学陈述；此筛选及中文提示词属于适配，必须披露，不能宣称完全复现官方实现。复合句需按确定的陈述提取规则处理，不能为个别方法调整边界。

没有实质医学陈述的答案记 N/A，不能把完全拒答记满分。失败或无法完成判断另记状态，不作为零分或拒答。主表报告有效题的单题分数均值，同时报告有效题数与陈述数。1减忠实性只是同一指标的补数，不另外创造一个指标名称。

裸模型也可在生成后接受同一证据池审查，但须说明它生成时没有接收证据。该比较不代表其医学知识正确率。

## 2. 辅助指标：Citation Recall（引用召回）

出处：[ALCE，EMNLP 2023，§3.3](https://aclanthology.org/2023.emnlp-main.398/)。

输入：最终答案中的被评价句子、句子的引用标识、引用所对应的真实指南片段。引用解析必须保存原文与出处，SEC-RAG 的证据单元还需保留原始片段中的适用条件。

过程：检查该句是否带有效引用，以及这些引用拼接后能否支持整个句子。出现引用编号不等于获得支持。

    单句得分 = 1：存在有效引用，且联合引用内容支持整句
    单句得分 = 0：无引用、引用失效或联合内容不支持整句
    单题引用召回 = 单句得分之和 / 被评价句子数

输出：逐句原文、引用映射、支持判断及依据、单题分数。医学句筛选与上下文解析属于本实验适配，须记录；不可把先前的“被支持事实比例”直接称为原版 ALCE 引用指标。

裸模型不要求提供引用，对应列记 N/A。无实质医学句同样记 N/A，另报数量。原论文的评价模型与我们的本地模型不同，因此不能直接继承其可靠性结论。

## 3. 必须随分数报告的数量

同一张四方法对照表展示忠实性、引用召回、各项有效题数、完全证据拒答数、评价失败数。完整结果另保留每题四方法答案对照。

完全证据拒答指没有实质医学回答、明确表示证据不足；空答案、程序失败和其他无内容输出不能自动算拒答。

    完全证据拒答比例 = 完全证据拒答题数 / 成功完成答案类型判断的题数

这是一项描述性计数，不是新的质量指标。其作用是解释分数的分母：一个方法只回答8题，另一个回答29题，不能仅凭前者忠实性更高就声称整体更优。可补充共同有实质回答题目的配对结果，但必须同时保留全量数量，避免隐藏拒答。

## 4. 不再作为当前评价主线的内容

暂停 QCARE 完整性、关注度，以及自定义四类支持标签评分和额外 Top20 审查池。旧文件和诊断结果留存追溯，不继续作为正式评分要求。不能通过删指标或修改评价器来追求 SEC-RAG 高分。

历史版本不随公开源码分发。

## 5. 自动评价的可靠性边界

公开公式不保证本地4B模型能正确提取和判断医学陈述。已有范围误判说明这一点。1题、9题诊断只能检查流程和已知错误；重复一致也不等于正确。

优先对照公开实现核对提示词、陈述单位和聚合方式，再决定实现适配。没有专家标注时，可以报告透明的自动评价结果及局限；不同评价模型的敏感性比较只能提供补充证据，不能替代医学金标准。不能保证审稿人会接受，也不能把自动评分当作临床结论。

当前评价模型选择尚未最终锁定；本文件不授权隐藏下载、切换模型或付费调用。


## 当前实现与命令

从完整回答按句分类，混合医学事实与证据不足说明优先作为医学句。每次仅对一个医学句提取陈述，不提供完整答案，避免排除内容重新进入。每条陈述附逐字source_quote；程序检查引文位置，但不能证明语义等价。无法消解的指代保持原样，这可能限制陈述提取质量。

引用召回仍评价完整医学句，按原始引用恢复条件。记录代码/提示词/模型指纹、原始判断及分子分母；不同实现指纹不得混合续跑。该实现会随评价器产生分类、范围和支持判断误差，不能只凭运行成功判断可靠。

```bat
python -s scripts/run.py evaluate --source-dir <生成结果目录> --check-only
python -s scripts/run.py evaluate --source-dir <生成结果目录> --workers 2
```

先准备本地Ollama qwen3:4b-instruct，默认服务127.0.0.1:11434。只读已保存答案，不调用生成模型。输出位于storage/experiments/evaluation/<时间>/，含汇总CSV、同题CSV、逐题JSON和implementation_snapshot。中断后使用相同source-dir并加--resume <时间目录>。

拒答记N/A，失败另记，报告有效题数。不要把不同有效题集合的均值直接当公平排名。合成示例评分只用于功能检查，不用于论文效果结论。
